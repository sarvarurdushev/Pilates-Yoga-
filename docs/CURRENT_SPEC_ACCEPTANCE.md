Audit checkpoint: 29 September 2026. The attached specifications are treated as requirements, not as instructions to discard the existing codebase or to claim success without evidence.

Status meanings: **DONE + VERIFIED locally** means the described behavior has a focused automated check on this working tree; it does not imply hosted or all-role browser acceptance. **PARTIAL** means there is working code but a stated part or required proof remains. **OPEN** means the acceptance test has not been met. Local browser checks covered Admin and Coach dashboards, a Coach program edit and new phase with Student projection, Student practice-only visit with named recorder, an exact visit-linked Coach note save/return path, and a detailed demo report. They did not complete the exact three-role journeys, actual WebGL rendering, browser photo/video upload acceptance or the hosted release. Separate local authenticated HTTP smoke tests completed real inference on a synthetic front-view photograph (15 numeric metrics) and a six-second synthetic movement clip (22 sampled frames and 9 numeric range signals), each with coordinates, progress records and an explicit visit link. The artificial clip validates the pipeline, not exercise recognition or clinical accuracy; neither test validates 3D or Render. The conservative tally remains **8 DONE + VERIFIED locally, 50 PARTIAL, 5 OPEN**. The existing Render service has **not** received this working tree.
