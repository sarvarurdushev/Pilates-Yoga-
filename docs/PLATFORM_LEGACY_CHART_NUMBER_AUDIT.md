# Anatomy and archived chart-number audit — 5 October 2026

This inventories chart, graph and prominent numeric families **outside** `web/src/platform` for requirements #41–42. It records source definitions separately from local renderer receipts; none is evidence of the hosted release. The active `web/index.html` loads `web/src/platform/app.js`; `web/src/studio/app.js` is retained code and is **not** the current entry point. The platform embeds `web/anatomy.html`. Its normal opening is the atlas alone; `web/src/session/boot.js` mounts the older recorder, posture check and movement screening only for an explicit `?legacy` or `?session=` URL. A session bundle may be real or explicitly marked synthetic. [PLATFORM_ACTIVE_ROUTES.md](PLATFORM_ACTIVE_ROUTES.md) records these exact entry conditions and source-return contracts. The platform chart audit is in [PLATFORM_CHART_NUMBER_AUDIT.md](PLATFORM_CHART_NUMBER_AUDIT.md).

“Default” below means visible once the named surface is opened, not that the normal studio dashboard opens that surface. “Comparison” means an actual earlier observation of the same subject, rather than two values from a reference model or two phases of an animation.
